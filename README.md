# Parliament Assistant

A simple web-based assistant dashboard designed to provide tools and quick-access resources related to parliamentary work.

## Features
- Clean HTML/CSS interface
- Dashboard-style layout
- Extendable architecture
- Lightweight (no backend required)

## Live Demo
https://amrdipoo.github.io/parliament-assistant/
